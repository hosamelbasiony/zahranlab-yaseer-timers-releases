# Zahran Lab Timer - Yaseer LIS — downloads

Laboratory timer assistant for **Zahran Labs**: it tracks every running test, alarms when a test or
protocol step is due, and includes the clinical lab calculators.
Powered by **[Yaseer LIS](https://www.facebook.com/yaseer.lis/)**.

This repository hosts the released installers only.

## Download

**[⬇ Download the latest version](https://github.com/hosamelbasiony/zahranlab-yaseer-timers-releases/releases/latest)**

| File | Use it for | 
|---|---|
| `ZahranLabTimer-Setup-v….msi` | Installing on a lab PC (recommended); keeps itself up to date |
| `ZahranLabTimer-Portable-v….zip` | Running without installing: unzip and open `ZahranLabTimer.exe` |

Requirements: Windows 10 or 11, 64-bit. Nothing else to install.

## Install

1. Download the `.msi` file and open it.
2. Follow the setup. No administrator rights are needed; it installs for the current Windows user.
3. If Windows shows "Windows protected your PC", click **More info → Run anyway**
   (the installer is not code-signed yet).

Installing a newer version over an older one keeps the running timers and your custom tests.

## Updates

The installed app checks this page for new versions and shows **Install now / Later / Skip this version**.
Nothing is installed without your consent, unless you turn on automatic updates in Settings; even then
it waits until no timer is running or ringing.

## What's inside

- Timers for the lab's tests, custom timers and multi-step protocols (e.g. ELISA incubation and wash steps)
- Patient name or barcode on each timer; critical tests shown first; filter by status
- Alarm sounds; keeps running in the system tray; compact mini window
- Lab calculators: HOMA2 & HOMA-IR, INR & ISI, eGFR, Friedewald LDL, dilution factor,
  corrected calcium, creatinine clearance, A/G ratio
- Arabic interface with light and dark themes
